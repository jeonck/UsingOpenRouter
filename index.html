샘플 코드

아래는 OpenRouter API와 상호작용하는 Python 예제 코드입니다. 다양한 모델을 테스트해보세요:

import requests
import json

API_KEY = "your_openrouter_api_key"
MODEL_ID = "deepseek/deepseek-prover-v2:free"  # 여기에 원하는 모델 ID 입력

headers = {
    "Authorization": f"Bearer {API_KEY}",
    "Content-Type": "application/json"
}

payload = {
    "model": MODEL_ID,
    "messages": [
        {"role": "user", "content": "쿠버네티스의 개념과 핵심 구성요소를 설명해주세요."}
    ],
    "temperature": 0.7  # 0에 가까울수록 일관된 답변, 1에 가까울수록 창의적인 답변
}

response = requests.post(
    "https://openrouter.ai/api/v1/chat/completions",
    headers=headers,
    data=json.dumps(payload)
)

# 응답 처리
if response.status_code == 200:
    result = response.json()
    if "choices" in result and len(result["choices"]) > 0:
        print(result["choices"][0]["message"]["content"])
    else:
        print("API 응답에 예상된 형식의 데이터가 없습니다.")
else:
    print(f"오류: {response.status_code}")
    print(response.json())
복사됨!

your_openrouter_api_key를 실제 API 키로 대체하세요. 모델 ID를 변경하여 다른 모델을 테스트할 수 있습니다.

OpenRouter란?

OpenRouter는 300개 이상의 AI 모델에 접근할 수 있는 통합 API 게이트웨이입니다. 단일 API 키로 다양한 AI 제공업체의 모델을 사용할 수 있어 개발자와 사용자에게 편리함을 제공합니다.

다양한 모델

무료 및 유료 모델 모두 동일한 API로 접근 가능합니다.

지능형 라우팅

각 요청에 가장 적합한 모델로 자동 라우팅합니다.
